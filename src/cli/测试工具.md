# deepSeekCode 工具测试用例集

> 本文档用于系统性地测试 deepSeekCode 的每一个可用工具，确保其功能正常。
> 测试分为若干测试套件（Suite），按工具类别分组。

---

## 测试前准备

- [ ] 确认工作区为一个干净的 Git 项目（或临时测试目录）
- [ ] 确认网络连通（用于搜索/抓取类测试）
- [ ] 准备一个简单的测试文件 `test-tmp/test-base.txt`，内容为 `Hello World`
