# deepSeekCode Agent 工具说明

本文档记录了当前 agent（deepSeekCode）所拥有的全部工具及其用途说明。

---

## 一、只读 / 检索类

| 工具名 | 用途 |
| --- | --- |
| `getTime` | 返回当前服务器的日期与时间（本地时区）。 |
| `read_file` | 读取指定文件的文本内容，自动带物理行号，支持大文件分片读取。 |
| `list_dir` | 扫描并精简列出项目的工作区目录树（自动套用忽略规则）。 |
| `view_symbol_outline` | 通过抽象语法树（AST）提取文件的符号大纲（类、接口、函数、导出项等）。 |
| `search_grep` | 在工作区所有文件中检索匹配的代码行，返回带行列号的平铺线索。 |
| `glob` | 按文件名 glob 模式查找文件（如 `**/*.ts`），自动过滤忽略项。 |
| `read_project_guide` | 读取项目根目录下的 AI 行为指引（CLAUDE.md / AGENTS.md / AGENT.md）。 |
| `inspect_dependencies` | 读取项目 package.json 中声明的第三方依赖及版本清单。 |

## 二、文件操作类

| 工具名 | 用途 |
| --- | --- |
| `create_file` | 在工作区内创建一个全新文件并写入初始内容（已存在则拒绝）。 |
| `write_file` | 将完整内容全量写入指定文件（覆盖式，适合大段重写）。 |
| `edit_file` | 对指定文件做局部精准修改（old_str 精确匹配替换）。 |
| `move_file` | 移动或重命名文件/目录（同卷原子操作，目标已存在则拒绝）。 |
| `delete_path` | 从磁盘永久删除文件或整个文件夹目录（不可逆，请谨慎）。 |

## 三、Git 操作类

| 工具名 | 用途 |
| --- | --- |
| `git_status` | 查看当前 Git 工作区状态（分支、改动、暂存/未跟踪文件清单）。 |
| `git_log` | 查看当前分支最近的提交历史（短哈希、日期、提交说明）。 |
| `get_git_diff` | 获取工作区中未提交的代码改动（红绿色 Diff 差异）。 |
| `git_commit` | 将暂存区改动提交为一次新的 Git commit（可选 stage_all 暂存全部）。 |

## 四、命令执行类

| 工具名 | 用途 |
| --- | --- |
| `run_command` | 在工作区执行 shell 命令（跑测试 / 构建 / git 等），流式返回输出。 |

## 五、联网检索类

| 工具名 | 用途 |
| --- | --- |
| `web_fetch` | 抓取指定公开 URL 的网页内容并转为干净 Markdown（默认拦截内网，防 SSRF）。 |
| `web_search` | 联网搜索外部资料（API 文档、报错解法、最新信息等）。 |

## 六、任务 / 后台管理类

| 工具名 | 用途 |
| --- | --- |
| `todo_write` | 创建或更新会话的任务清单（整表覆盖写，用于多步任务跟踪）。 |
| `run_in_background` | 在后台启动长连接/常驻命令（dev server、watch 等），立即返回 task_id。 |
| `get_background_output` | 查看指定后台任务的最近输出日志与运行状态。 |
| `stop_background_task` | 终止指定的后台任务（连同子进程树）。 |
| `spawn_agent` | 创建拥有独立执行环境的子 agent 处理隔离的子任务，完成后汇总结论返回。 |

## 七、会话 / 变更回退类

| 工具名 | 用途 |
| --- | --- |
| `undo_list` | 列出当前会话内所有可回退的文件/目录变更（按时间倒序）。 |
| `undo_restore` | 回退会话内的一次文件/目录变更（恢复旧内容 / 删除新建文件）。 |

## 八、计划 / 技能类

| 工具名 | 用途 |
| --- | --- |
| `enter_plan_mode` | 进入计划模式：先只读调研、产出完整实现方案，经用户审批后再实现。 |
| `exit_plan_mode` | 计划模式专用：提交完整实现方案供用户审批。 |
| `load_skill` | 加载指定技能的完整指令（如 TDD 测试驱动开发工作流）。 |

---

> 以上为当前 agent（deepSeekCode）的全部工具清单。
